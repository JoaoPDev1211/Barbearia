 Barbearia
Projeto de site responsivo para uma barbearia, com foco em design moderno, usabilidade e organização de conteúdo. Desenvolvido com HTML, CSS e JavaScript puro, este projeto simula um site institucional para uma barbearia fictícia, com informações, imagens e navegação fluida.
